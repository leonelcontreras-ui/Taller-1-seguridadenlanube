## 📑 1. Análisis del Pilar de Seguridad (AWS)

*Breve descripción de los principales aspectos analizados en el Pilar de Seguridad de AWS.*

* **Gestión de Identidades y Accesos (IAM):** AWS IAM permite administrar usuarios, grupos y roles mediante políticas de permisos. Esto permite aplicar el principio de mínimo privilegio, otorgando a cada identidad únicamente los permisos necesarios para realizar sus funciones.

* **Detección y Respuesta a Incidentes:** La seguridad en AWS requiere monitorear las actividades y eventos de los recursos para identificar comportamientos anómalos o accesos no autorizados. Los registros (*logs*) y sistemas de monitoreo permiten analizar eventos, detectar amenazas y facilitar una respuesta rápida ante incidentes.

* **Protección de Datos (En tránsito y en reposo):** Los datos deben protegerse durante su almacenamiento y transmisión mediante mecanismos de cifrado. También es importante establecer controles de acceso y políticas de seguridad que eviten que usuarios o servicios no autorizados puedan consultar o modificar la información.

* **Seguridad de la Infraestructura:** AWS utiliza diferentes mecanismos para proteger la infraestructura, como el aislamiento de recursos, controles de red y configuraciones de seguridad. La segmentación de redes y el establecimiento de reglas de acceso ayudan a reducir la superficie de ataque y limitar posibles amenazas.
